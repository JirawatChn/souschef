# shadcn Sidebar & Header Redesign

**Date:** 2026-05-07  
**Status:** Approved

## Goal

Migrate the sousChef AI frontend to shadcn/ui, redesign the sidebar and header with shadcn components, add a mobile slide-in drawer, and maintain the warm food theme (cream/amber palette).

## Approach

Full shadcn migration — replace all `radix-ui` direct imports with shadcn-wrapped equivalents. Remove `@radix-ui/themes` entirely. One unified component system throughout.

## Setup

- Run `npx shadcn@latest init` with **New York** style
- Install components: `sheet`, `button`, `dropdown-menu`, `scroll-area`, `separator`
- Customize shadcn CSS variables in `index.css`:
  - Background: `#FFFEF8` (current cream)
  - Primary/accent: amber tones matching current `#FFE4B5` / `#fde6ba`
- Remove `@radix-ui/themes` package and its stylesheet import from `App.tsx`

## Sidebar (Desktop)

- Fixed, 250px, left — same position as today
- Background: `linear-gradient(to bottom, #FFF6D1, #FFE4B5)` inline style on `<aside>`
- Top row: title "sousChef AI" + shadcn `Button` (variant `ghost`, size `icon`) with pencil icon → `/`
- Nav links: shadcn `Button` (variant `ghost`) — full-width, left-aligned, icon + label. Active route highlighted with darker amber background (check via `useLocation`)
- `Separator` between nav links and chat history section
- Chat history in shadcn `ScrollArea`
- History items: hover-reveal delete using shadcn `Button` (variant `ghost`, size `sm`)

## Mobile Layout

- `MobileHeader` bar (full-width, `h-14`, cream `#FFFEF8` background) — visible on mobile only (`md:hidden`)
  - Left: `Button` (variant `ghost`, size `icon`) with hamburger `Menu` icon — `SheetTrigger`
  - Center: "sousChef AI" title
  - Right: Personality + Language dropdowns (same as desktop header)
- shadcn `Sheet` opens from the left, renders `<SidebarContent>` — the same component used by the desktop sidebar
- Sheet open state managed in `MainLayout` via `useState`

## Header (Desktop)

- Visible on desktop only (`hidden md:flex`) — same position as today
- Personality dropdown: shadcn `Button` (variant `outline`) trigger + shadcn `DropdownMenu`
- Language dropdown: shadcn `Button` (variant `outline`) trigger + shadcn `DropdownMenu`
- Item hover color: `hover:bg-amber-50` (replaces `hover:bg-gray-100`)

## Component Architecture

```
MainLayout
├── MobileHeader (md:hidden)
│   ├── SheetTrigger → Sheet → SidebarContent
│   ├── Title
│   └── Personality + Language dropdowns
├── Sidebar (hidden md:block, fixed)
│   └── SidebarContent
└── Content area
    ├── Header (hidden md:flex)
    └── {children}
```

`SidebarContent` — shared component containing nav links and chat history. Rendered by both desktop `Sidebar` and the mobile `Sheet`.
